# Audyt i Plan Zabezpieczeń dla Firmy Spedycyjnej "SpeedWay"

**Cel projektu:**<br>
Głównym celem projektu jest zabezpieczenie infrastruktury IT firmy spedycyjnej przed atakami typu ransomware (szyfrującymi dane) oraz oszustwami finansowymi realizowanymi za pomocą phishingu.

**Opis działania:**<br>
Przeprowadziłem kompleksowy audyt infrastruktury IT firmy spedycyjnej, identyfikując kluczowe luki bezpieczeństwa, takie jak brak MFA, nieszyfrowane dyski i brak segmentacji sieci. Na podstawie frameworku CIS Controls v8 zaprojektowałem docelową architekturę oraz opracowałem 18-miesięczny harmonogram wdrażania zabezpieczeń.

**Wnioski:**<br>
Nauczyłem się w praktyce łączyć techniczne aspekty bezpieczeństwa z wymaganiami biznesowymi, tak aby wprowadzane zmiany nie paraliżowały pracy operacyjnej firmy. Projekt uświadomił mi również, jak ogromne znaczenie ma edukowanie pracowników (Security Awareness) oraz umiejętne uzasadnianie kosztów inwestycji (ROI) przed zarządem.
